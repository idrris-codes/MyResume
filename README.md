# Idris Multilanguage Cinematic Portfolio

## Что есть

- Выбор языка при входе
- English / Русский / Тоҷикӣ
- Кнопка смены языка в углу
- Cinematic дизайн без слишком футуристичного стиля
- Анимации на компьютере, планшете и телефоне
- Отдельный раздел для ботов
- Отдельный раздел для сайтов
- Пустые карточки-шаблоны для будущих проектов

## Как заменить фото

Положи фото в папку `assets` и назови:

```txt
profile.jpg
```

Потом в `index.html` замени:

```html
assets/profile-placeholder.svg
```

на:

```html
assets/profile.jpg
```

## Как изменить тексты

Все тексты на 3 языках находятся в `script.js` в объекте `translations`.

## Как добавить реальные ссылки

В `index.html` замени `href="#"` на настоящие ссылки проектов.

## Запуск

Открой `index.html` в браузере.
